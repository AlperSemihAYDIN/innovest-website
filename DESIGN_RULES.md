# Innovest Design Rules — Tüm sayfalar için geçerli

## Spacing
- Section padding: minimum paddingTop: 120px, paddingBottom: 120px
- Etiket → Başlık arası: marginBottom: 16px
- Başlık → Açıklama arası: marginTop: 20px, marginBottom: 40px
- Açıklama → Buton arası: marginTop: 40px
- Kart grid gap: minimum 32px
- Kart iç padding: minimum 36px 32px

## Tipografi
- Başlıklar: fontWeight 400-500, asla bold/700
- Açıklama metinleri: fontWeight 300, lineHeight 1.9, color rgba(255,255,255,0.65)
- Etiketler: fontSize 11px, fontWeight 600, letterSpacing 0.2em, color #C9A84C
- italic kullanma

## Kartlar
- borderRadius: 16px
- border: 1px solid rgba(255,255,255,0.08)
- background: rgba(255,255,255,0.03)
- hover border: rgba(201,168,76,0.25)

## İkonlar
- Container: 52x52px, borderRadius 12px, background rgba(201,168,76,0.1)
- İkon rengi: #C9A84C

## Genel
- Tailwind yerine inline style kullan — Tailwind override sorunları yaşanıyor
- Her değişiklikten önce bu dosyayı oku
